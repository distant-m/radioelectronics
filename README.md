# Радіоелектроніка, її компоненти і плати

Двомовний (UA/EN) курс-застосунок про читання електронних плат: від однієї деталі до цілого пристрою. 17 модулів, тести з перемішуванням, фото з Wikimedia Commons з указанням авторів, анімації, робота без інтернету.

Інформація, зазначена в курсі, стосується стандартних практик плат, електроніки та частот. У курсі не враховано спеціалізовані військові прошивки та радіоелектроніку.

## Структура

```
index.html            стартова сторінка: вибір мови й режиму оновлень, перенаправлення на версію
versions.json         яка версія остання + що нового
manifest.webmanifest  щоб курс встановлювався як застосунок
sw.js                 офлайн-режим (service worker)
icons/                іконки застосунку
v1/                   уся версія 1.0 (НЕ змінювати після публікації)
  index.html, app.js, draw.js, anim.js, styles.css
  content/            модулі m01–m17, словник, автори фото
  img/                фото (webp)
  svg/                малюнки
  fonts/              шрифти IBM Plex (Open Font License)
```

## Публікація на GitHub Pages (як Pitch Ladder)

1. На github.com → **New repository**, наприклад `radioelectronics`, **Public**.
2. **Add file → Upload files** → перетягніть **вміст** цієї папки (не саму папку) → **Commit changes**.
3. **Settings → Pages → Build and deployment → Source: Deploy from a branch**, гілка `main`, папка `/ (root)` → **Save**.
4. За 1–2 хвилини курс буде за адресою `https://<ваш-логін>.github.io/radioelectronics/`.

Встановити на телефон:
- **Android (Chrome):** ⋮ → «Додати на головний екран» / «Встановити застосунок».
- **iPhone (Safari):** «Поділитися» → «На початковий екран». Навчатися в самому застосунку, а не в Safari: поступ у них окремий.

## Як випускати нову версію (v2, v3…)

Старі папки **ніколи не змінюються** — так у тих, хто не оновлювався, нічого не ламається.

1. Скопіюйте `v1/` у `v2/` і внесіть зміни в `v2/`.
2. У `v2/app.js` змініть `VERSION = 'v2'` і `VERSION_LABEL = '1.1'` (або `'2.0'`).
3. У `versions.json` додайте запис про `v2` і поставте `"latest": "v2"`.
4. Завантажте зміни на GitHub.

Поступ зберігається за постійними ID модулів і питань, тож переходить у нову версію. Якщо в новій версії змінено вже пройдений модуль — підніміть йому `cv` (2, 3…), і в учня біля модуля зʼявиться позначка «Оновлено», але залік не зникне.

## Обмеження доступу з росії (Cloudflare)

GitHub Pages сам не вміє блокувати країни. Потрібен свій домен і безкоштовний Cloudflare:

1. Купіть домен (≈10 $/рік) у будь-якого реєстратора.
2. Зареєструйтесь на cloudflare.com (план Free), додайте домен, змініть NS-сервери в реєстратора на ті, що дасть Cloudflare.
3. У Cloudflare → DNS: запис `CNAME` `course` → `<ваш-логін>.github.io` (проксі «помаранчева хмарка» — увімкнено).
4. У GitHub → Settings → Pages → Custom domain: `course.ваш-домен` → Save, потім увімкнути **Enforce HTTPS**.
5. У Cloudflare → Security → WAF → Custom rules → Create rule: *Field* `Country` *equals* `Russia` → *Action* `Block`. Можна додати Білорусь.

Важливо: прямий адрес `*.github.io` лишається відкритим, а VPN обходить будь-яке блокування за країною. Це бар’єр, а не замок. Справжній захист — у курсі лише відкрита інформація.
